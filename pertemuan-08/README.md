## Fitur
1. Navigasi halaman Beranda, Tentang, Rencana Kegiatan, dan Kontak.
2. Form untuk menambahkan rencana kegiatan mahasiswa.
3. Input nama, kategori, tanggal, lokasi, dan deskripsi kegiatan.
4. Validasi formulir menggunakan JavaScript.
5. Validasi data menggunakan PHP.
6. Pengiriman data menggunakan metode POST.
7. Penyimpanan data sementara menggunakan Session.
8. Pengalihan halaman menggunakan metode Post-Redirect-Get (PRG).
9. Menampilkan kembali data kegiatan yang sudah dikirim.
10. Tetap mempertahankan fitur formulir Kontak dari pertemuan sebelumnya.
