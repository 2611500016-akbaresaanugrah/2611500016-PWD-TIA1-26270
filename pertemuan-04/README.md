
# Pertemuan 4 - CSS3 Layout dan Responsive Web Design

# Pengembangan

- Perubahan yang dilakukan: Memisahkan CSS ke file "style.css", menggunakan Box Model, Flexbox untuk navigasi, CSS Grid untuk tata letak, dan media query agar tampilan menyesuaikan ukuran layar.
- Commit dan push GitHub: Dilakukan secara bertahap untuk setiap tahap pengembangan (Box Model, Flexbox, Grid, dan Responsive).

# Pengujian

- Perangkat bergerak: Menguji tampilan pada ukuran 375 × 667 piksel. Konten ditampilkan dalam satu kolom dan navigasi tersusun secara vertikal.
- Desktop: Menguji tampilan pada ukuran 1366 × 768 piksel. Konten ditampilkan dalam dua kolom, navigasi tersusun horizontal, dan bagian Kontak menggunakan lebar penuh.
- Galat dan perbaikan: Memeriksa tampilan pada ukuran layar yang berbeda untuk memastikan semua bagian terlihat rapi dan mudah digunakan.
- Validasi CSS: CSS diperiksa menggunakan W3C CSS Validator. Hasilnya menunjukkan tidak ditemukan error pada kode CSS.
