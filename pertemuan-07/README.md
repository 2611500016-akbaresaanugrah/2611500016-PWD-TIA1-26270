Deskripsi

Pada pertemuan 7, saya melanjutkan proyek dari P6 dengan menambahkan fitur pengolahan formulir menggunakan PHP.

Fitur yang Dikerjakan

1. Menggunakan metode GET dan POST.
2. Menerima data formulir menggunakan PHP.
3. Membuat validasi data formulir.
4. Memeriksa format email dan semester.
5. Mengamankan data menggunakan "htmlspecialchars()".
6. Menggunakan session untuk menyimpan data sementara.
7. Menerapkan metode PRG agar formulir tidak terkirim ulang saat halaman dimuat ulang.

Cara Menjalankan

1. Buka Laragon.
2. Klik Start All.
3. Buka proyek melalui VS Code.
4. Jalankan melalui browser menggunakan localhost.
5. Isi formulir dan klik tombol Kirim.
